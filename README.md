## 🚀 Como rodar o projeto

### 🔧 Pré-requisitos
- Node.js instalado
- Git
- Gerenciador de pacotes (npm ou yarn)

### ▶️ Instalação

```bash
git clone https://github.com/user/repo.git
cd repo
npm install
```
### ▶️ Execução
```bash
npm start
```
